# Capstone 1 – HR Attrition Analysis – Cerlin
This project analyzes why employees leave the company.
Business Questions: 1) Which dept has high attrition? 2) Does overtime affect? 3) Salary impact?
Files: Python Notebook, SQL Script, Power BI Dashboard, Datasets, Report PDF, Presentation
Tools: Python (Random Forest), SQL, Power BI (DAX)
Key Findings: Overtime=Yes has high attrition, Sales dept high, Low salary attrition high.
